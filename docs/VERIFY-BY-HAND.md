# 真机验证清单（一次重启即可逐条确认）

本清单用于确认 0.1.29 – 0.1.89 期间的全部改动**在真实宿主里成立**。
所有自动化测试都跑在假宿主上，逻辑层面覆盖完整，但真实渲染与真实宿主交互只能由人或真机确认。

## 0. 准备

| 步骤 | 做法 | 预期 |
|---|---|---|
| 0.1 重启应用 | 完全退出 DeepSeek Harness，再打开 | 插件的客户端 bundle 会重新加载（不重启则仍是旧版本） |
| 0.2 确认版本 | 顶部「分屏」面板 → 顶栏最右的刷新图标，**悬停**看提示 | 提示里出现 `0.1.89`（或更高）；若显示更旧，说明 bundle 没重新加载 |
| 0.3 打开控制台 | 应用内打开 DevTools（如无入口可跳过） | 后续 7.3 项需要它 |

> 版本也可用一条命令确认：`node -e "console.log(require('C:/Users/king_/.dsh/profiles/desktop/node_modules/dsh-multiview/package.json').version)"`

## 1. 从侧栏把会话放进分屏（0.1.29 / 0.1.32）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 鼠标悬停在左侧任意**会话行**上 | 行尾出现一个**分屏图标**（在「归档」「置顶」旁） |
| 1.2 | 点击它 | 顶栏切到分屏；该会话出现在某一格里 |
| 1.3 | 若所有格都已绑定且不足 4 格 | 会**新增一格** |
| 1.4 | 若已 4 格全满 | **替换当前聚焦的那一格**（格数不变） |
| 1.5 | 点会话行的 `…` → 菜单 | 有一条「在分屏中打开」，点击效果同 1.2 |
| 1.6 | 对**已在分屏里**的会话再点分屏图标 | 图标是高亮状态，点击只是把焦点移过去，不会重复投放 |

| 1.7 | 在两格都已绑定的分屏里点格头的 ⇄ | 该格原位变成选择器；选中另一对话后**格数不变**，另一格不动 |
| 1.8 | 在空格里输入一个**对话正文里出现过**的词（≥2 个字） | 列表出现该对话，并在右侧显示命中**片段**；只输入 1 个字不应触发宿主检索 |
| 1.9 | 在选择器里按 `Escape` | 返回原来的对话，什么都不改 |

## 2. 注意力（0.1.29 / 0.1.34 / 0.1.38）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 在一格里让 AI 开始跑，然后切到别的格 | 跑完后，那一格的状态点变成「有新结果」状态 |
| 2.2 | 点那个状态点 | 焦点跳到该格 |
| 2.3 | 按 `Mod+Alt+J` | 跳到下一个「等待你处理」或「有新结果」的格 |
| 2.4 | 只有「运行中」的格时按 `Mod+Alt+J` | **不跳转**（运行中不算需要你） |
| 2.5 | 侧栏「分屏」图标 | 有格需要你时，图标右上角出现小圆点；悬停或读屏标签会说「N 格需要你处理」 |

## 3. 键盘（0.1.29 / 0.1.32）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 聚焦分割线后按 `→` / `←` | 每次移动 **2%** |
| 3.2 | 按住 `Shift` 再按方向键 | 每次 **5%** |
| 3.3 | 按 `Home` / `Enter` / `Space` | 恢复均分 |
| 3.4 | `Mod+Alt+S` | 当前格与**下一格**交换位置 |
| 3.5 | `Mod+Alt+[` / `Mod+Alt+]` | 焦点在格之间移动 |

## 4. 保存的布局（0.1.29 / 0.1.30 / 0.1.31 / 0.1.40 / 0.1.43 / 0.1.54）

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | 绑定 2 个以上会话 | 「Views」按钮出现计数 |
| 4.2 | 打开 Views → 点 ✎ → 输入名字 → 回车 | 名字生效；之后改动布局，**名字不会被覆盖** |
| 4.3 | 应用一套布局 | 顶栏标题后显示**该布局的名字**；临时拼的分屏不显示名字 |
| 4.4 | 在**正在使用**的布局上点 ✕ | 条目立刻消失，**不会马上又冒出来** |
| 4.5 | 交换两个格的位置 | 布局条目**数量不变**（不会多出一条近似重复） |
| 4.6 | 归档其中一个会话后，应用那套布局 | 形状照旧恢复，被归档的那格**清空**；该布局条目**仍然存在**（不被静默删除） |

## 5. 边界行为（0.1.41 – 0.1.51）

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 2 格分屏里，某格是空的 | 该空格**没有 ✕**（不能把分屏删成 1 格） |
| 5.2 | 空格子的格头 | **没有 ⤢**（空窗格不能最大化） |
| 5.3 | 4 格分屏，聚焦第 4 格，点 `2` | 缩到 2 格后，**你正在看的那一个仍在**（且在第一格） |
| 5.4 | 在某格里归档该会话 | 该格立刻清空，位置不变 |
| 5.5 | 把一个正在最大化的格里的会话移到别的格 | 自动**退出最大化**（不会停在空窗口） |
| 5.6 | 全新工作区（没有会话）打开分屏 | 空格里显示「还没有会话，先在左侧新建一个」；搜索无结果时显示「没有匹配的会话」 |

## 7. 窄窗与运行时（0.1.33 / 0.1.89 待验证项）

| # | 操作 | 预期 |
|---|---|---|
| 7.1 | 把侧栏拖得很宽（或把窗口缩窄），直到内容区 < 900px | 只显示**一**格 + 顶栏出现格切换器；切换器上带每格状态点 |
| 7.2 | 点切换器上的其他格 | 该格成为显示的那一格 |
| 7.3 | 反复拖宽/拖窄触发上述切换，观察 DevTools 控制台 | **不再出现** `ResizeObserver loop completed with undelivered notifications` |
